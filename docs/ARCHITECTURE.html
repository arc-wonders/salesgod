SalesGod architecture

An outbound AI phone sales agent for Hindi, Hinglish and English callers. Rules and a state machine decide what to say, an LLM only decides how to word it, and a validator stops the LLM from ever writing a price or a number itself.

Speaker lock (WeSpeaker)

input 80-bin Kaldi fbank, 16 kHz, mean-normalised, no dither (needs ≥ 0.5 s) e = f(fbank) / ‖f(fbank)‖₂ 256-d, L2 normalised S = E·Eᵀ pairwise cosine of turns ≥ 1 s caller = mean{ eᵢ : S[best, i] ≥ 0.5 }, best = argmaxᵢ #{ j : Sᵢⱼ ≥ 0.5 } keep ⇔ e·caller ≥ 0.40 same speaker 0.5–0.8, other 0–0.3

A second, cheaper background filter compares prosody: a turn is dropped when it is ≥ 10 dB quieter than the caller, or ≥ 5 dB quieter and its pitch is > 6 semitones away.

04Speech to text

model Whisper large-v3, fp16, beam_size=5, temperature=0, condition_on_previous_text=False hint turn < 1.6 s → force the current call language (no detection) detect share_en = P(en) / (P(en) + P(hi) + P(ur)) lang = en if share_en ≥ 0.92 (0.50 when the call is already in English) retry if lang = en: decode again as hi; switch if mean_logprob(hi) + 0.15 ≥ mean_logprob(en) drop a segment if any holds: no_speech > 0.6 ∧ logprob < −0.7 compression_ratio ≥ 2.4 logprob ≤ −1.2 no_speech > 0.4 ∧ rms < 0.025 no_speech > 0.5 ∧ logprob < −0.3 ∧ rms < 0.035 rms < 0.008 concurrency 4 transcriptions at once (semaphore)

05Prosody (pitch and loudness)

Switched off by default (ACIE_PROSODY=0) because a caller asked for it to be off. The features are still computed and logged on every turn.

YIN frame 640 (40 ms), hop 160 (10 ms), F0 ∈ [75, 400] Hz, threshold 0.15 d(τ) = Σ (x_t − x_{t+τ})² d'(τ) = d(τ) · τ / Σ_{j≤τ} d(j) cumulative-mean normalised difference τ* = first τ with d'(τ) < 0.15, walked to the local minimum, parabolic interpolation F0 = 16000 / τ* octave errors removed: F0 > 2·median or F0 < median/2 st = 12 · log₂(F0 / 100 Hz) semitones baseline = median of the same caller's last 8 turns (outliers > 7 st from the median dropped) Δpitch = st − base_st ratio = σ_st / max(base_σ, 0.5) Δloud = dB − base_dB arousal = [0.45·clip(Δpitch/4) + 0.30·clip(ratio − 1) + 0.25·clip(Δloud/6)] · min(1, n_base/3) ignored if |Δpitch| > 7 st (another voice) if arousal > 0.25 and the words are negative: frustration += 0.40a, urgency += 0.15a if arousal > 0.25 otherwise: engagement += 0.25a, frustration += 0.10a if arousal < −0.25: engagement −= 0.40|a|

Measured on live calls: median caller F0 140 Hz (p90 172), loudness −22 dBFS, speech rate 2 words/s.

The 12 intents are affirm, deny, tell_more, price, benefits, callback, human_agent, clarify, goodbye, slow_down, personal and small_talk. The rules keep the final word; the NLU only replaces a rule intent of unknown, tell_more, benefits, goodbye, affirm or deny.

10Decision engine (what to say)

keyword classifier score(i) = Σ w_k over keyword hits, after masks syntax "phrase" whole-word match "bhej*" prefix on the last word "=matlab" whole utterance (fillers removed) priority clarify → human_agent → callback → (deny | affirm) gated affirm / deny only while a question is pending, and only if their score ≥ best open intent fallback highest score among non-weak intents
sales FSM (session.dialog["pending"]) opening → intro → pitch → close → confirm → link_sent → end any "no" → one soft re-offer (max_reoffers = 1, only if frustration < 0.5) → goodbye "later" → callback, end price / benefit / FAQ answered at any stage after each answer, one nudge forward: intro → offer price → 1 benefit → ask about link link is asked again only after ≥ 3 turns and ≥ 1 benefit frustration ≥ 0.4 → apologise, no selling line

Playbook picker (pre-written decision tree)

for each node n (16 nodes for claude-pro, 10 for fitzone-gym): score = 2.5·[keyword regex hit] + 1.0·[rule intent ∈ n] + 1.0·[NLU intent ∈ n] + 2.0·[NLU objection ∈ n] + 0.5·[question topic ∈ n] + 1.5·[signal range node holds] skip n if buying / frustration / confusion falls outside its range pick argmax score, only if score ≥ 2.0; the LLM says 1–2 of its unused talking points

Context ledger (whole-call memory)

An append-only event log per call. It tracks what was promised (link, callback, removal), what was quoted, what was told, the customer's questions and objections, and their decision (accepted, declined, later or undecided). A plain-text summary of it goes into every prompt as "CALL SO FAR".

High-stakes turns (price, closing the sale, opening, compliance, safety) set llm_allowed = False. Those turns speak only the reviewed template. The LLM once swapped the offer price and the original price inside a correct-looking sentence.
